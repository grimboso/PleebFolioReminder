# PleebFolio Reminder

PleebFolio Reminder saves Omnium Folio choices per spec and talent loadout.

Set a spec default, add loadout overrides where you need them, and PleebFolio will swap the saved Folio choice when your talents change. If you change the Folio by hand, you can save the new choice, keep it temporary, or restore the saved one.

Use `/pfolio` to open the settings. PleebUI integration is optional.
